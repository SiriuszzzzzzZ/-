# 设计原则速查

> 来源：`docs/superpowers/specs/2026-05-10-counselor-platform-design.md` §九

## 六大设计原则

1. **低压力 > 高参与**：宁可学生一周来两次轻轻松松，不要每天来打卡压力重重
2. **存在感 > 表达欲**：让学生"被感觉到存在"比"鼓励表达"更底层
3. **去神化辅导员**：辅导员不是监察者，是有情绪起伏的人
4. **允许消失**：退出、潜水、沉默都是正常状态，不是问题
5. **不做假共情**：系统不伪装关心，只做匹配、等待、给选择
6. **不制造社交内卷**：不排行、不攀比、不公开量化"被喜欢程度"

## 产品定位

"低压力关系基础设施"——一种不需要高社交能力，也能被连接的系统。

- 微信是强关系，QQ 群是噪音关系，钉钉是权力关系
- 本平台解决：被看见、被理解、被连接、被允许缓慢成长

## P0 功能清单（必须完整）

1. 🌤 匿名情绪天气 — 一键选4种情绪，聚合趋势，<5人保护，连续阴雨预警
2. 👻 辅导员凡人时刻 — 辅导员也可选情绪，🌪时有提示
3. 🆘 一分钟求助 — 技能/情绪分流，情绪类默认匿名，撤回无痕
4. 👻 辅导员隐身模式 — 自由区不显示在线状态，数据隔离

## P1 功能清单（应该完成）

5. 💨 弱表达系统 — 5种粒子，24h消失
6. ✨ 隐形成长记录 — 每周限1次，附原因，单向匿名，推荐长期未被点亮者
7. 🌱 生长节奏 — 30天轨迹，不惩罚消失
8. 🔍 事务自动消失 — 3种信号
9. 🛡 低存在模式 — 可开关，降低推送

## 内容健康比例

| 类型 | 目标占比 |
|------|---------|
| 日常轻内容 | ~50% |
| 共同活动 | ~25% |
| 求助支持 | ~15% |
| 深度情绪 | ~10% |

## 隐私分级

三级：树洞内容 < 自由区普通内容 < 召唤区内容

- 树洞：AI不分析，仅词云
- 自由区：辅导员不实时监控
- 召唤区：@辅导员 或情绪求助 直达
